# Processed Data and Validation

This directory contains cleaned analytical datasets, derived summaries, data-quality audit results and cross-validation outputs generated during the project.

## Cleaned datasets

The cleaned datasets preserve the source observations while standardising the data for analysis. No source observations were removed during the documented cleaning stage.

## Derived analytical datasets

Derived summaries support comparisons across governance dimensions, selected benchmark cases and regional summaries.

## Data-quality validation

The project includes a formal data-quality audit covering completeness, uniqueness, identifier consistency, score ranges and source-specific exceptions.

## Governance register

The current governance framework register contains nine entries. Its change log records subsequent updates to the original register.

## Important interpretation notes

- Published benchmark scores are not independently re-scored.
- Missing observations are not imputed.
- Rounded scores should not be interpreted as evidence of identical model performance.
- Selected cases and regional summaries are descriptive, not representative population estimates.
- Validation checks establish consistency against documented rules; they do not independently establish the validity of the original publisher's methodology.
