# Power BI Semantic Model Tables

This directory contains the 13 prepared CSV tables used to construct the Power BI semantic model.

The tables are organised into:

- Dimension tables.
- Fact tables.
- Bridge tables for governance relationships.
- Data-quality and analytical findings tables.

The accompanying manifests document the intended table structure, primary keys and relationships.

The dataset preparation and relationship validation were completed before the Power BI report encountered a local semantic-model issue.

The final interactive dashboard and validated PBIX will be published separately after report recovery and reconstruction.

No corrupted PBIX file is included in this repository.
