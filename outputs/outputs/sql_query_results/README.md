# SQL Query Results

This directory contains CSV outputs generated by executing the analytical SQL queries in `sql/02_analytical_queries.sql`.

The outputs provide queryable summaries of model performance, governance dimensions, selected benchmark cases, reported regional results, framework records, governance controls, data-quality checks and documented analytical findings.

These files support inspection of the SQL results without requiring the reader to execute the database queries.

The results are descriptive and should be interpreted within the methodological limitations documented in the main project README.
