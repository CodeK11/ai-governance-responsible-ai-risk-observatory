# Governance Mapping Validation

This directory contains the validation outputs produced for the governance control and evidence-mapping datasets.

The validation work checked:

- Unique control identifiers.
- Valid references to registered controls and frameworks.
- Duplicate framework-control mappings.
- Duplicate evidence mappings.
- Evidence-reference validity.
- Correct control status classifications.
- Reconciliation of the framework mapping matrix.

The recorded governance mapping validation completed with 8 of 8 checks passing.

These checks establish structural consistency against the project's validation rules. They do not independently establish the quality or effectiveness of real-world governance implementation.
