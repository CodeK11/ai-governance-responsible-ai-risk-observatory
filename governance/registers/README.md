# Governance Registers

This directory contains the structured governance control register and its associated mapping datasets.

| Dataset | Description |
|---|---|
| governance_control_register.csv | Project-defined governance controls, ownership themes, focus areas and status |
| governance_control_framework_map.csv | Links between governance controls and the framework register |
| governance_control_evidence_map.csv | Supporting evidence references associated with governance controls |

The control register contains 16 entries. Their status is explicitly documented and should not be interpreted as implementation or effectiveness evidence.

The mapping datasets support framework coverage analysis and evidence traceability
