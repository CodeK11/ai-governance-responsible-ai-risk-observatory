# Governance Analysis Outputs

This directory contains derived analytical summaries of the governance control register and its supporting mappings.

The outputs examine:

- Overall control coverage.
- Framework-to-control mapping distribution.
- Governance follow-up focus areas.
- Evidence-reference source distribution.
- Control-to-framework mapping coverage.

The datasets are derived from the project's governance registers. They describe the structure and coverage of proposed controls rather than the effectiveness of implemented controls.
