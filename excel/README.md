# Integrated Excel Workbook

This directory contains the consolidated analytical workbook developed for the AI Governance & Responsible AI Risk Observatory.

**File:** `AI_Governance_Observatory_Integrated_Workbook.xlsx`

The workbook contains 29 worksheets, including:

- Start Here and Executive Summary.
- Source and processed analytical datasets.
- Benchmark dimension and selected-case summaries.
- Regional benchmark summaries.
- Governance framework and control registers.
- Governance mapping and evidence-reference datasets.
- Data dictionary and relationship documentation.
- Power BI table and CSV export manifests.

The workbook provides an accessible, consolidated view of the project's analytical outputs.

The figures are based on published benchmark summaries and project-derived calculations. Their methodological limitations are documented in the main project README.

The workbook is an analytical reporting deliverable, not a certification of AI-system safety or regulatory compliance.
